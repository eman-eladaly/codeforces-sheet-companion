# Codeforces Sheet Companion

A lightweight Chrome extension that helps you track your progress in Codeforces sheets.

## Features

- ✓ Solved Here
- ↗ Solved Elsewhere
- ○ Unsolved
- Sheet progress overview
- Works directly inside Codeforces sheets

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions/`
3. Enable Developer Mode.
4. Click "Load unpacked".
5. Select the project folder.
